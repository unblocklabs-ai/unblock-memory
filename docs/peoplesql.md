# PeopleSQL (Retired Design)

This earlier plugin-owned dossier-maintenance design has been retired. The
current product boundary and agent workflow are documented in
[`planning/people-whisperer-agent-owned-dossiers.md`](planning/people-whisperer-agent-owned-dossiers.md).

PeopleSQL now stores people, identities, dossiers, per-person injection
preferences, and durable thread-person injection receipts. The OpenClaw agent
maintains dossiers with ordinary people and memory tools; the plugin only
stores, matches, and injects.
